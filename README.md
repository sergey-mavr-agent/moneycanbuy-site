# moneycanbuy.fun site

Static build of the moneycanbuy.fun front end: dares with rewards in escrow on Ethereum mainnet, judged by the IMD
swarm. Plain HTML, CSS and JS with relative paths: no build step, no backend.

`config.json` lists the mainnet contracts the site reads and the public RPC endpoints it uses. The site holds no keys
and no funds: every action is a transaction the visitor signs in their own wallet.

Contracts and the full project: [github.com/sergey-mavr-agent/moneycanbuy.fun](https://github.com/sergey-mavr-agent/moneycanbuy.fun).
